
# Verity AI

An evidence-first AI Research & Fact-Checking Agent.

## Current Status

Early prototype. The Streamlit research interface is working.
Live web search, evidence verification, and report generation
are not implemented yet.

## Planned Features

- Web source discovery
- Evidence extraction and comparison
- Claim-level citations
- Transparent uncertainty and limitations
- Research report export
- Automated tests and evaluation

## Tech Stack

- Python 3.12
- Streamlit
- Git and GitHub

## Run Locally

Activate the virtual environment, then run:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Project Goal

Build a reproducible research workflow that distinguishes
retrieved evidence from generated conclusions.
